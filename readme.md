#  MovieTracker — Список просмотренных фильмов

## Описание
Веб-приложение для отслеживания просмотренных фильмов. Позволяет добавлять фильмы с указанием жанра и рейтинга, отмечать статус просмотра ("Хочу посмотреть" / "Просмотрено") и управлять списком. Проект разработан в рамках практики по ПМ.11.

## Стек технологий
* **Frontend:** React, Vite
* **Backend:** Node.js, Express
* **База данных:** JSON (lowdb)
